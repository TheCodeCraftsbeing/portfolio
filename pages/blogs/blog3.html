My Journey with the Dell Precision T-1700 Server

Introduction

Setting up a personal server is both a challenge and a rewarding experience. In this blog series, I’ll share my journey of building a versatile home server using a Dell Precision T-1700, from troubleshooting hardware issues to deploying a fully functional media server accessible over the Internet. This first post focuses on how I acquired the server, dealt with unexpected hardware challenges, and laid the groundwork for an efficient and reliable system.

Acquiring the Dell Precision T-1700

When I decided to set up a home server, I wanted something reliable yet cost-effective. After researching, I settled on the Dell Precision T-1700, a workstation known for its durability and performance. I managed to find one at a good price, excited to put it to work as the foundation of my server setup.

Facing the DMS-59 Pin Challenge

The Dell T-1700 came equipped with an older GPU that used a DMS-59 connector. This uncommon interface proved to be a problem, as I didn’t have the appropriate adapter to connect it to a modern monitor. At first, I thought replacing the adapter would solve the issue, but it became clear that the GPU itself was outdated and caused compatibility issues with the motherboard.

The Solution: Swapping the GPU

After some trial and error, I decided to replace the GPU entirely. I selected a dedicated GPU that was compatible with the system and would provide the performance I needed for virtualization and media streaming. With the new GPU installed, the display issue was resolved, and I was ready to proceed.

Lessons Learned: Compatibility Matters

One key lesson from this experience is that even if you have an older GPU lying around, it might not be compatible with your motherboard or intended use case. It's always worth checking compatibility thoroughly before starting a project like this.

Switching to a dedicated GPU not only solved my immediate problem but also opened up new possibilities for my server setup.

Configuring the Proxmox Server

With the hardware ready, the next step was setting up Proxmox, a powerful open-source platform for virtualization. Here’s a quick overview of the setup:

  • Installing Proxmox: I downloaded the Proxmox ISO and installed it on the Dell T-1700. The installation was straightforward, and the system was up and running in no time.
  • Creating Virtual Machines (VMs): Proxmox allowed me to create multiple VMs for different purposes, such as running applications or testing new tools.
  • Setting Up LXC Containers: Lightweight LXC containers were perfect for hosting services that didn’t require full virtualization, saving resources while maintaining flexibility.

Adding Jellyfin and Samba for Media and Storage

To make the server functional for everyday use, I added two essential services:

  • Jellyfin Media Server: Jellyfin is an open-source media server that lets me organize and stream my media library. Setting it up was as simple as installing the software, adding my media files, and configuring user access.
  • Samba for Shared Storage: Samba enabled me to share files across my network seamlessly. I created shared folders accessible from all my devices, making it easy to manage and back up data.

Enabling Remote Access with Tailscale

One of my primary goals was to access the server remotely, even when outside my home network. This is where Tailscale came in.

  • Why Tailscale? Tailscale is a mesh VPN that allows secure access to your devices without complex configurations. With Tailscale, I could connect to my server from anywhere in the world.
  • Access Without a VPN: While Tailscale worked perfectly for most devices, some devices (like Smart TVs) couldn't use VPNs. To address this, I configured Jellyfin to face the Internet, allowing me to access my media server directly, bypassing the need for a VPN.

Conclusion

Setting up the Dell Precision T-1700 as a home server was a learning experience filled with challenges and rewards. From overcoming hardware compatibility issues to configuring Proxmox, Jellyfin, Samba, and Tailscale, each step brought me closer to my goal of a versatile, accessible, and efficient home server.
