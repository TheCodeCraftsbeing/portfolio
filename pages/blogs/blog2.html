Azure Open AI - Part 1

What is Azure Open AI?

Azure Open AI is a collaboration between OpenAI and Microsoft Azure, providing faster and more reliable access to AI models while meeting enterprise standards.

How it works?

After getting access, you can use multiple OpenAI models in the portal, including GPT-3.5-turbo, DALL-E, and more. They have a separate portal for this service (https://oai.azure.com/portal/). Access is granted upon approval of your request.

Azure Open AI offers multiple templates for common use cases like customer support bots and string format assistants. The advantage of Azure Open AI is the ability to deploy AI models in minutes for common use cases.

For custom use cases, there is an option called fine-tuning. As the name suggests, you can tune an AI model for your specific needs. I am currently exploring how to fine-tune these models.

How do they make money from this service?

Azure Open AI charges based on token consumption. The words you use to interact with the AI are broken into tokens for processing. For detailed pricing, refer to the Microsoft official link (https://azure.microsoft.com/en-us/pricing/details/cognitive-services/openai-service/).

Accessing Azure Open AI

To access Azure Open AI, you need to request access through the Azure portal. Once approved, you can start using the models and templates provided. The portal offers a user-friendly interface to manage and deploy AI models efficiently.
